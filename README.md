# rentenrechner-deutschland.com

Kostenloser Rentenrechner für Deutschland: Bruttorente in Nettorente umrechnen, Regelaltersgrenze nach Geburtsjahr, Rente mit 63, Rentenbesteuerung, Betriebsrenten-Freibetrag. Statisches HTML/CSS/JS, kein Backend, alle Berechnungen client-side. Formeln gegen offizielle DRV/BMF-Quellen sourcierte (siehe `research/sourcing-tracker.csv`).

Live: https://rentenrechner-deutschland.com/

## Free Companion Tools

- [Regelaltersgrenze Schnellcheck](https://sadiyaqeen92639572-cloud.github.io/regelaltersgrenze-rechner/) — schneller Check deiner Regelaltersgrenze und deines abschlagsfreien Alters (Rente mit 63) nach Geburtsjahr. Powered by rentenrechner-deutschland.com.

Eingaben in den Rechner

Renteneinkommen, Geburtsjahr und andere Daten, die du in einen Rechner auf dieser Website einträgst, werden ausschließlich client-side über JavaScript in deinem Browser verarbeitet. Sie werden niemals an unsere Server übertragen, von uns weder erfasst noch gespeichert. Beim Schließen oder Neuladen der Seite werden sie gelöscht.
